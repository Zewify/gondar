The first release.

- The menu bar shows the current session's usage as a percentage.
- Click it for a panel listing every limit — the session, the weekly limits and any per-model ones — with how much is used and when each resets.
- "Pop out" opens an always-on-top window with one line per limit, above other windows on every Space and over full-screen apps.
- Gondar follows the account Claude Code is signed in to, and switches when you sign in to another one.
- Optional: connect Claude Code's status line through the bundled `gondar-feed` tool, and the numbers update live while you work (Settings → "Connect Claude Code's status line…").
